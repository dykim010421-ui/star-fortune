# Star Fortune v2 설계

## 목표
재미로 만든 단일 HTML 별자리 운세(`legacy/star_fortune.html`)를 완성도 높은 정적 웹사이트로 고도화한다.
비주얼 · 내용 · UX · 공유 네 축을 균형 있게 올린다. **유료 서비스·API는 일절 쓰지 않는다.**

## 스택 (전부 무료)
- Vite + 바닐라 JS(ES 모듈) + Three.js
- astronomy-engine: 브라우저에서 오늘의 태양·달·행성 위치 계산
- Yale Bright Star Catalog(퍼블릭 도메인), d3-celestial 별자리 선(BSD-3)
- Lucide 아이콘, Google Fonts
- 배포: GitHub Pages (정적 빌드, `base: './'`)

## 구조
- `src/sky/` 하이퍼리얼 하늘 (관측자가 천구 안에 있는 플라네타리움 시점)
  - 실제 별 약 9천 개: 등급→밝기·크기, 색온도(K)→색, PSF 코어+헤일로, 밝은 별 회절 스파이크, 대기 반짝임
  - 절차적 은하수: 은하 좌표계 기반 띠 + 노이즈 먼지대 + 은하 중심부 밝기, 은하면에 몰린 희미한 배경 별
  - 황도 12궁 실제 별자리 선, 오늘의 행성 위치 표시
  - 후처리: 블룸, ACES 톤매핑, 필름 그레인·비네트 (모바일은 품질 자동 하향)
  - 별자리 클릭 → 카메라가 해당 별자리로 회전·줌인 → 운세 오버레이
- `src/astro/` 천문 계산 (행성 황경→별자리, 달 위상, 수성 역행)
- `src/fortune/` 운세 엔진: 기존 문장 풀 + 오늘의 실제 행성 배치 해석 문장, 날짜·별자리 시드로 결정적 생성
- `src/ui/` 오버레이, 생일 입력(localStorage), 별자리 목록, 공유 카드(PNG)

`sky/`, `astro/`, `fortune/`은 서로 의존하지 않고 `main.js`만 이들을 잇는다.

## 운세 규칙
- 점수(1~5) = 시드 기본값(3~5) + 천문 보정(±1), 1~5로 자름
  - 달이 내 별자리: 행운 +1 / 금성이 같은 원소: 애정 +1 / 화성이 내 별자리: 직업 +1
  - 수성 역행: 직업 −1 / 태양이 내 별자리(생일 시즌): 전체 기운 문장 추가
- "오늘의 하늘" 섹션: 실제 배치를 설명하는 문장 2~4개
- 같은 날 같은 별자리는 항상 같은 결과
